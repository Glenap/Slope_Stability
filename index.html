// METHODOLOGY

How It Works

01

Limit Equilibrium

The solver divides the potential failure mass into vertical slices and applies moment/force equilibrium. Bishop's Simplified and Janbu's Simplified methods are both implemented with full iterative convergence.

FoS = Σ[(c·b + W·tanφ)/mα] / Σ[W·sinα]
02

Critical Circle Search

A 15×15 grid search over slip circle centres followed by 200 random perturbations locates the circle yielding the minimum FoS — the true critical failure surface.

min FoS over (cx, cy, R) ∈ domain
03

Dataset Generation

Latin Hypercube Sampling over 6 parameters generates 1000 well-spread simulations covering the full design space without clustering or gaps.

[c, φ, E, γ, β, H] → [FoS_B, FoS_J, u_max]
04

ML Surrogate

XGBoost, LightGBM, MLP and GPR are trained on the LEM dataset. The best model achieves R² > 0.97 on held-out test data with inference at ~0.01 ms per sample.

Speed-up: ~50,000× over direct LEM
// UGP-II NOVELTY MODULE 1

Probabilistic Reliability & Monte Carlo Risk Engine

Classical LEM requires ~14 hours to evaluate 100,000 stochastic slope realizations. Our Physics-Informed surrogate evaluates 10,000 realizations in < 0.2s, quantifying the exact Probability of Failure (Pf) and Cornell Reliability Index (β) under soil parameter uncertainty.

Landslide Forensic Inverse Back-Analysis Engine

When a slope collapses in the field (FoS = 1.0), laboratory tests frequently overestimate shear strength. This module solves the inverse problem in milliseconds to reconstruct the mobilized shear strength envelope (c_mob vs. φ_mob).

About This Project

This interface is the frontend for a 4-month geotechnical ML research project. The backend Python modules implement the full pipeline: LEM solver → dataset generation → surrogate training → SHAP explainability. This UI visualizes the simulation directly in the browser using the same mathematics.
